A program that sums up Monday 23 November 2026's world news in one image: a newspaper front page drawn entirely in code. Lead story: COP31 collapses in Antalya with no climate pact. Also: tankers hit in the Strait of Hormuz, a drone strike near Kyiv as Trump pushes a wider ceasefire, the Banten factory fire, and the day in brief.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, about 20 KB). Stdlib only, no network, deterministic: two runs produce byte-identical output.
